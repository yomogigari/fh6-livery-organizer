Navigator Bridge for FH6 v0.0.26

Navigator Bridge for FH6 v0.0.26 は、この補助ツールの初公開版です。
この文書では現在の仕様と利用方法のみを説明します。

=================================

■ Navigator Bridge for FH6 とは

Navigator Bridge for FH6 は、Livery Organizer for FH6 で選んだペイント位置へ、
FH6本体の「マイデザイン」画面上のカーソルを移動するための補助ツールです。

Organizerでは各ペイントに、次のような現在の位置番号を表示します。

  #603 / #302U

#603 は現在の実スロット通し番号、#302U はFH6「マイデザイン」画面上の
302列目・上段（U）の位置を表します。

番号をクリックして「FH6で選択デザインへ移動」または F キーを実行すると、
Organizerは選択した移動先と現在の最終実スロット番号、移動設定をNavigator Bridgeへ渡します。

Navigator Bridgeは、FH6「マイデザイン」の開始位置 #001U を起点として、
指定位置まで何回カーソルキーを押せばよいかを計算します。
左右は、先頭から右へ進む経路と、左キーで最終列へ循環して戻る経路を比較し、
キー入力回数が少ない方を使います。対象がD（下段）の場合は最後に下キーを1回送ります。

たとえば、最終実スロットが #827（最終列 #414U）の状態で
Organizerから #603 / #302U を指定した場合、Bridgeは #001U から #302U までの
移動回数を計算します。この例では右へ301回より、左循環を使う113回の方が短いため、
左キーを113回送る移動計画になります。

その後、BridgeがForza Horizon 6のウィンドウを検出して前面へ切り替え、
計算したカーソルキーを設定された間隔でWindowsの標準入力APIから自動入力します。
これにより、Organizerで選択した番号に対応するFH6上のペイント位置へカーソルを移動します。

要するに、次の流れです。

  Organizerで #603 / #302U を選ぶ
       ↓
  移動先・最終実スロット・待ち時間設定をBridgeへ渡す
       ↓
  Bridgeが #001U からのカーソル移動回数を計算する
       ↓
  FH6を前面化する
       ↓
  左 / 右 / 下のカーソルキーを自動入力する
       ↓
  指定したペイント位置へカーソルを移動する

Navigator Bridgeは任意機能です。Organizerの一覧化、検索、整理、CSV / Excel出力などは、
Bridgeを導入しなくても利用できます。

Organizer連携欄には、現在の「実行形式: Windows EXE / Python」と、Windowsへ登録されている
「連携登録先」を表示します。登録先が現在のBridgeと異なる場合は「再登録が必要」と表示します。


■ ダウンロード済みペイントを探して「デザインを読み込み」へつなぐ

Navigator Bridgeの用途は、不要なペイントを整理・削除するときだけではありません。
ダウンロード済みのペイントから、現在運転しているマシンへ適用したいデザインを探すときにも利用できます。

FH6標準の「マイデザイン」で各ペイントについて確認できる情報は、
「サムネイル / タイトル / 作成者 / 作成者がUPした日付」の4項目です。
ペイント数が増えるほど、目的の車種や以前ダウンロードした特定デザインを、この情報だけを頼りに
FH6上で探し続けるのは手間がかかります。

Livery Organizerでは、車種・メーカー・年式・作成者・タイトルなどを使って検索・絞り込み・
並び替えができます。Organizer側で先に使いたいデザインを特定し、#603 / #302U のような位置を
Navigator Bridgeへ渡せば、BridgeがFH6「マイデザイン」の該当位置までカーソルを移動します。

その後、利用者がFH6上で「デザインを読み込み」を実行すると、選んだペイントを現在運転している
マシンへ適用できます。

  Organizerで使いたいペイントを検索・特定する
       ↓
  #実スロット / #列U・D を移動対象にする
       ↓
  FキーでNavigator Bridgeへ移動指示
       ↓
  BridgeがFH6「マイデザイン」の該当位置へカーソルを移動
       ↓
  利用者がFH6の「デザインを読み込み」を実行
       ↓
  現在運転しているマシンへペイントを適用

Bridge自身は「デザインを読み込み」、ペイント選択、決定操作を行いません。
対象位置までのカーソル移動だけを補助し、最終操作は利用者がFH6上で行います。


■ 「FH6で削除済み（仮）」と組み合わせたマイデザイン整理

Navigator Bridgeは、Organizerの「FH6で削除済み（仮）」と組み合わせると、
FH6「マイデザイン」を順番に整理する用途で特に便利です。

FH6でペイントを1件削除すると、その後ろにあるペイントのスロット位置は前へ詰まります。
OrganizerはFH6の画面や削除結果を自動で読み取らないため、削除したデザインをOrganizer側でも
「FH6で削除済み」にして、一時的に一覧から除外します。するとOrganizerが残っているペイントの
#実スロット / #列U・D を再計算し、次のBridge移動に新しい位置を使えるようになります。

整理例:

  1. Organizerの削除候補・再DL重複整理・類似比較などから対象を選ぶ
  2. #603 / #302U などをクリックして、Fキーまたは移動ボタンを実行する
  3. BridgeがFH6の対象位置までカーソルを移動する
  4. FH6上で利用者がペイントを確認し、不要なら削除する
  5. Organizerの「FH6マイデザイン順」で同じデザインを「FH6で削除済み」にする
  6. Organizerが残りの位置番号を詰め直す
  7. 再計算された番号から次の対象を選び、Bridgeで移動する

この流れを繰り返すことで、Organizerで整理対象を判断しながら、FH6上の実物へ移動して
「マイデザイン」を連続して整理できます。

Bridgeはペイントを削除しません。ペイント内容の確認、削除、最終確定はFH6上で利用者が行います。
また、通常の移動計算は #001U を起点にするため、「#001Uへ戻す」をOFFで使う場合は、
移動前にFH6のカーソルを #001U に合わせてください。繰り返し整理では必要に応じて
「#001Uへ戻す」をONにすると、毎回の起点をそろえやすくなります。


■ 重要: FH6の現在位置を読み取る機能ではありません

Navigator Bridgeは、FH6の画面を画像認識・解析したり、ゲーム内部のペイント位置や
現在のカーソル位置を読み取ったりして、移動結果を確認する仕組みではありません。

Bridgeが行うのは、Organizerから受け取った番号をもとに #001U からの移動操作を計算し、
設定された間隔でキー入力を送ることです。
FH6ウィンドウの検出・前面化と、入力前の前面状態の確認は行います。

そのため、PCやFH6の処理負荷、フレームレート、ウィンドウ切替の遅延などによって
キー入力が取りこぼされた場合、Organizerで指定した位置まで正しく移動できず、
FH6上のカーソル位置がずれることがあります。

位置がずれる場合は、OrganizerまたはBridgeの「FH6移動設定」で、
キー間隔や各待ち時間を長めに調整してください。


■ 開始位置 #001U について

通常の移動計算は #001U を起点にしています。

「#001Uへ戻す」がOFFの場合:
FH6「マイデザイン」を開いた直後など、カーソルを #001U に合わせてから実行してください。

「#001Uへ戻す」がONの場合:
Bridgeは移動前に固定操作 ESC → RET を各1回送信し、マイデザインを開き直して
#001Uへ戻してから通常のカーソル移動を開始します。

このリセット機能もFH6の画面や現在位置を読み取って確認するものではありません。
設定された待ち時間で固定操作を行います。


■ Organizerからの使い方

1. Navigator Bridgeを単独起動します。
2. 「連携を登録」を一度実行します。
   「実行形式」と「連携登録先」がGUIに表示されるので、現在のBridgeが登録されていることを確認できます。
   Bridgeを別フォルダへ移動・ファイル名変更した場合、またはEXE版/Python版を切り替えた場合は、
   変更後のBridgeから「連携を登録」を再実行してください。
3. Livery Organizerで生成したHTMLを開きます。
4. カードや比較画面の #603 / #302U などの番号をクリックします。
5. Fキー、または「FH6で選択デザインへ移動」を実行します。
6. BridgeがFH6を前面化し、計算したカーソル操作を自動入力します。
7. 目的に応じて、FH6上で「デザインを読み込み」を実行するか、確認・整理・削除を行います。

Bridgeが担当するのは手順6までです。「デザインを読み込み」、選択、削除、確定などの最終操作は利用者が行います。

ブラウザから外部アプリを開く確認が表示された場合は、内容を確認して許可してください。
OrganizerとBridgeのローカル連携には navigatorbridgeforfh6:// を使用します。

Bridgeがすでに起動している場合は、別ウィンドウを増やさず既存インスタンスへ指示します。
Organizerから必要時に起動されたBridgeモードでは通常GUIを表示しません。


■ 標準FH6移動設定

キー間隔                 50ms
FH6切替後                500ms
横→上下                  200ms
左循環後の追加待ち       400ms
#001Uへ戻す              OFF
ESC後の待ち時間          500ms
RET後の待ち時間          800ms

PC環境やFH6の負荷によっては、標準値より長い待ち時間が必要になる場合があります。

共通設定の保存先:
%APPDATA%\Livery-Organizer-for-FH6\navigator-bridge-settings.json


■ 固定された安全境界

通常の位置移動でFH6へ送信できるキーは次の3種類だけです。

・左
・右
・下

「#001Uへ戻す」がONの場合だけ、移動開始前の固定操作として
Escを1回、Return（RET / Enter）を1回、この順序で送信します。

任意のキーコード、キー名、キー順序をOrganizerや外部URIから指定する機能はありません。
上、文字キー、ファンクションキーなどを位置移動用として送信しません。

標準のWindows入力APIを使用し、ゲームのメモリ、実行コード、ゲームファイル、
GameSaveを書き換えません。

ゲーム進行、経済、報酬、ランキング、競争行為、削除確定などを自動化することを
目的としていません。最終的な確認、「デザインを読み込み」、選択、削除、確定などは利用者自身が行います。


■ 保存場所を変更した場合の再登録

navigatorbridgeforfh6:// のWindows登録にはBridge本体の絶対パスが保存されます。

再登録が必要:
- Navigator-Bridge-for-FH6.exe / Pythonソースを別フォルダへ移動した
- Bridge本体のファイル名を変更した
- EXE版からPython版、またはPython版からEXE版へ切り替えた

通常は再登録不要:
- 同じフォルダ・同じファイル名のEXEを新しい版で上書きした

移動前に「解除」する必要はありません。移動後のBridgeを単独起動して「連携を登録」を実行すると、
現在のパスで登録が上書きされます。GUIの「連携登録先」が現在のBridgeと違う場合は
「Organizer連携: 再登録が必要」と表示されます。


■ 連携解除 / 削除

Navigator Bridgeを削除する場合は、先にBridgeを単独起動し、GUIの「連携を解除」で
navigatorbridgeforfh6:// のWindows登録を解除してください。

BridgeのIPC / ログ:
%LOCALAPPDATA%\Navigator-Bridge-for-FH6\

共有移動設定を残したい場合は、
%APPDATA%\Livery-Organizer-for-FH6\navigator-bridge-settings.json
を削除しないでください。
