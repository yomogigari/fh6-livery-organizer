# Livery Organizer for FH6 更新履歴

公開プレビュー版の主な変更内容を記録します。

---

## v0.4.58 Preview — 2026-08-29

- 任意の補助ツール `Navigator Bridge for FH6 v0.0.26` を初めて公開・同梱
- Organizerで選択した `#実スロット / #列U・D` へ、Fキーまたは「FH6で選択デザインへ移動」からFH6カーソル移動を支援
- Bridge GUIに「実行形式: Windows EXE / Python」とWindowsの「連携登録先」を表示
- Bridgeの保存場所・ファイル名・EXE/Python形態を変更した場合は、変更後のBridgeから「連携を登録」を再実行する仕様を文書化
- 同じ絶対パス・同じファイル名のEXEを上書き更新するだけなら通常は再登録不要
- BridgeはFH6の画面内容や内部カーソル位置を読み取らず、ペイントの読み込み・選択・削除・確定操作を自動化しない
- Windows EXE版 / Python版の双方を提供

v0.4.57 Preview以降、「FH6マイデザイン順」を実際の利用・整理作業に使いやすくするため、位置ジャンプ、仮削除後の位置再計算、Navigator Bridge連携、任意の一覧・比較画面からのFH6位置移動を追加しました。Organizerで目的のダウンロード済みペイントを探し、FH6の「デザインを読み込み」へつなぐ用途と、不要なペイントを連続整理する用途の両方を想定しています。あわせてアプリ名・保存先・出力ファイル名を整理し、リリース前のUIとヘルプを見直しました。

### FH6マイデザインの位置ジャンプ

「FH6マイデザイン順」で、現在の実スロット位置へ直接移動できるジャンプ機能を追加しました。

- `537` / `#537` の実スロット番号を指定
- `#269U` / `#269D` のFH6列＋上下位置を指定
- `RX-7` などの車種名を部分一致で検索
- 車種候補を ↑ / ↓ で選択
- Enterで確定・一致位置を巡回
- `Shift+←` / `Shift+→` で前後の一致へ移動
- `J` で位置・車種ジャンプ入力欄へフォーカス

実スロット番号とFH6位置は `#001 / #001U` のようにU/D表記で統一しました。

### ダウンロード済みペイントの適用を支援

Navigator Bridge連携は削除整理だけでなく、ダウンロード済みのペイントを現在のマシンへ適用するときにも利用できます。

FH6標準の「マイデザイン」で各ペイントについて表示される情報は「サムネイル / タイトル / 作成者 / 作成者がUPした日付」の4項目に限られるため、ダウンロード済みペイントが増えるほど、目的のデザインをFH6画面だけから探し出す手間が大きくなります。

Organizerでは車種・メーカー・年式・作成者・タイトルなどで検索・絞り込み・並び替えを行い、先に目的のペイントを特定できます。そのカードの `#実スロット / #列U・D` を移動対象としてNavigator Bridgeへ渡し、FH6「マイデザイン」の該当位置へ移動したあと、利用者がFH6の「デザインを読み込み」を実行することで、現在運転しているマシンへ目的のペイントを適用できます。

Navigator Bridgeは「デザインを読み込み」、ペイント選択、確定操作を自動化せず、該当位置までのカーソル移動だけを補助します。

### 「FH6で削除済み（仮）」とNavigator Bridgeを使った整理ワークフロー

FH6本体で削除したデザインをOrganizer上でも一時的に除外し、残ったペイントの現在位置を再計算できるようにしました。この機能はNavigator Bridgeとの組み合わせを想定しており、FH6「マイデザイン」の連続整理に利用できます。

- FH6マイデザイン順のカードから「FH6で削除済み」として一時非表示
- 残ったカードの実スロット番号とFH6位置を即時に詰め直し
- 再計算した位置を、次のNavigator Bridge移動にも使用
- 上部の「FH6削除済み（仮）」から1件ずつ、または全件を復元
- 同じ生成HTMLを閉じて開き直してもlocalStorageで状態を保持
- 新しくHTMLを生成した場合は仮削除状態を引き継がない

想定ワークフローは、Organizerで整理対象を選ぶ → `#実スロット / #列U・D` を選択してBridgeでFH6へ移動 → FH6上で利用者が確認・削除 → Organizerで「FH6で削除済み」にする → 残りの位置を再計算 → 次の対象へ移動、という流れです。

FH6で1件削除すると後続スロットが前へ詰まるため、「FH6で削除済み（仮）」でOrganizer側の位置を追従させることで、次のBridge移動でも現在のFH6位置と対応しやすくなります。

この状態はOrganizer内だけの一時情報であり、GameSave内のLiveryを削除・変更しません。Navigator Bridgeもペイントの選択・削除・確定操作は行わず、最終確認と削除は利用者がFH6上で行います。

### Navigator Bridge for FH6連携

任意の補助ツール `Navigator Bridge for FH6 v0.0.26` を追加し、OrganizerからFH6本体の「マイデザイン」上の選択位置へ移動できるようにしました。

Bridgeの基本動作は、Organizerで選択した `#603 / #302U` などの移動先と現在の最終実スロット番号を受け取り、FH6「マイデザイン」の `#001U` を起点として必要なカーソル操作を計算し、その結果を `左 / 右 / 下` のキー入力としてFH6へ送信するものです。左右は右方向と左循環の短い方を選び、D（下段）の場合は最後に下キーを1回送ります。詳しい仕組みは同梱の `NAVIGATOR-BRIDGE-README.txt` にまとめました。

Organizer側では、カードに表示される実スロット番号やFH6位置をクリックして「FH6移動対象」を選択し、次の方法でBridgeへ移動指示を渡せます。

- 「FH6で選択デザインへ移動」ボタン
- `F` キー

Bridgeがすでに起動している場合は既存インスタンスへ指示を渡します。Organizerから必要時に起動されたBridgeモードでは通常GUIを表示しません。

ローカル連携には `navigatorbridgeforfh6://` を使用します。

### すべての並び順・比較画面からFH6へ移動

FH6位置を「FH6マイデザイン順」だけの機能ではなく、Organizer全体で利用できる共通ナビゲーション情報として扱うようにしました。

- メーカー順
- 車名順
- マイデザイン順
- 作成者順
- タイトル順
- 日時・年式順
- 整理状態・整理進捗順
- ペイント件数・バイナル数順
- 類似ペイント比較
- 選択中のペイント比較
- 再DL重複整理

各画面で現在の `#実スロット / #列U/D` を確認し、クリックしてFH6移動対象に設定できます。

仮削除後も同じ共通位置情報を再計算するため、各並び順・比較画面で現在のFH6実スロットと対応します。現在のFH6に実スロットが存在しない項目は「FH6位置なし」として移動対象にできません。

### `F` キーでFH6移動

FH6移動対象が選択されている場合、`F` キーで「FH6で選択デザインへ移動」を実行できるようにしました。

- 通常一覧で利用可能
- 類似比較 / 選択比較 / 再DL重複整理のモーダル内でも利用可能
- 入力欄、テキストエリア、選択欄では無効
- Ctrl / Alt / Shift併用時は無効
- キー長押しによる連続起動を防止
- 選択中の番号には「移動対象」を表示

### Navigator Bridgeの安全境界

Bridgeの送信可能キーを用途に合わせて固定しました。

通常の位置移動:

- 左
- 右
- 下

任意設定の「#001Uへ戻す」がONの場合だけ、移動開始前に固定シーケンスとして以下を各1回送信します。

- Esc
- Return（RET / Enter）

外部連携URIから任意のキーコード、キー名、キー順序を指定することはできません。上、文字キー、ファンクションキーなどを位置移動用として送信しません。

BridgeはForza Horizon 6を検出して前面化できた場合だけ入力を送信します。標準のWindows入力APIを使用し、ゲームのメモリ、実行コード、ゲームファイル、GameSaveを書き換えません。

BridgeはFH6の画面内容を画像認識・解析したり、ゲーム内部のペイント位置やカーソル位置を参照したりせず、Organizerから渡された移動先と設定値に従って、指定間隔で固定キー入力を送信する方式です。FH6ウィンドウの検出・前面化と前面状態の確認だけを行います。

このため、PCやFH6の処理負荷、フレームレート、ウィンドウ切替の遅延などで入力が取りこぼされると、Organizerで指定したペイント位置と実際のカーソル位置がずれる場合があります。必要に応じてキー間隔や各待ち時間を長めに調整してください。

### FH6移動設定

Organizerの生成HTMLからBridge用の待ち時間を調整できるようにしました。

v0.4.58 / Bridge v0.0.26の標準値:

```text
キー間隔                 50ms
FH6切替後                500ms
横→上下                  200ms
左循環後の追加待ち       400ms
#001Uへ戻す              OFF
ESC後の待ち時間          500ms
RET後の待ち時間          800ms
```

Organizerの「共通設定を保存」で、次の共有設定へ保存できます。

```text
%APPDATA%\Livery-Organizer-for-FH6\navigator-bridge-settings.json
```

新しくOrganizer HTMLを生成すると、共有設定を初期値として読み込みます。HTMLを開いた後の設定変更はブラウザlocalStorageにも保持します。

### 対応環境

開発・動作確認はMicrosoft Store / Xbox App版を中心に行っています。

Steam版でも利用者から正常動作の報告があります。ただし、開発側がSteam環境を正式に検証したことを意味するものではありません。

### 互換性・安全性

- OrganizerはFH6のGameSaveとゲーム本体を引き続き読み取り専用で扱います。
- GameSave配下をレポート出力先として使用できません。
- Organizerの整理操作・仮削除はブラウザlocalStorageに保存され、GameSaveを書き換えません。
- Livery fingerprintの基本規則とsnapshot重複排除の考え方を維持しています。
- 現在のFH6セーブ内に別スロットとして存在する再ダウンロード完全一致は、引き続き別カードとして保持します。
- Organizer / Navigator Bridgeはいずれも非公式・非営利のファンメイドツールです。

### リリース前確認

実データで生成した最終開発版 v0.4.57-r23 HTMLについて、以下を確認しました。

```text
ペイントカード        827件
車種                  304件
メーカー               53
作成者                 115人
Vehicle DB             660 Car IDs
再DL完全一致           1組 / 2件
実スロット番号         #001 ～ #827
最終FH6位置            #414U
```

あわせて以下を確認しています。

- 827カードのキーがすべて一意
- 実スロット番号 #001 ～ #827 に欠番・重複なし
- FH6位置のU/D計算が827件すべて一致
- HTML内idの重複なし
- 生成JavaScriptの構文エラーなし
- OrganizerとNavigator Bridgeの公開候補構成で実機総合操作確認済み
- Navigator Bridge v0.0.26 EXEのレジストリ登録、Organizerのボタン / FキーからFH6への移動を実機確認済み
- 左循環後の追加待ち400msを含む最終設定で実機動作確認済み

公開ソースでは、このr23の機能内容を変更せずOrganizerのバージョン番号を `v0.4.58` に更新しています。

## v0.4.57 Preview — 2026-08-24

v0.4.56 Preview以降、FH6本体の「マイデザイン」と照合しやすい表示、再ダウンロード重複の整理機能、類似候補の確認導線、リリース前診断を強化しました。

### 「マイデザイン順」を追加

- FH6本体の「マイデザイン」に合わせた並び順を追加しました。
- 並び順は `Car ID 昇順 → 取得日時の古い順` です。
- 通常の一覧では絶対位置を `#001`、`#002`… の通し番号で表示します。
- 絞り込み中も番号は振り直さず、FH6上の絶対位置を維持します。

### 「FH6マイデザイン順」を追加

FH6本体の「マイデザイン」画面と直接見比べやすい専用表示を追加しました。

- 1列につき上・下の2件を配置する横スクロール表示
- FH6位置表示
- ← / →キー、前へ / 次へボタンで1列ずつ移動
- 先頭と末尾を循環して移動
- 通常のマウスホイール（縦回転）を横移動として利用可能
- タイトルをFH6に合わせて大文字表示
- カード内の主要情報を `タイトル → 作成者 → FH6表示日付` の順で表示

### FH6表示日付に対応

- FH6本体の「マイデザイン」カードに表示される日付を解析し、`DD/MM/YYYY` 形式で表示します。
- 再ダウンロード重複の整理画面でも同じFH6表示日付を確認できます。

### 再ダウンロード完全一致を別ペイントとして管理

- 現在のFH6セーブ内で別 `Livery_*` スロットとして存在する完全一致ペイントは別カードとして表示します。
- 過去snapshotだけに残る同一内容の履歴コピーは従来どおり重複排除します。
- 再DL重複の専用整理画面を追加しました。

### 類似候補の確認を強化

- `画像一致`
- `同一作者・同名`

の理由を区別して表示し、理由別の絞り込みと比較を追加しました。

### 動作診断を強化

マイデザイン通し番号、FH6実スロット、FH6位置、FH6表示日付、再DL重複などの整合性確認を強化しました。
