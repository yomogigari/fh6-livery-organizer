# Livery Organizer for FH6 v0.4.62 Preview — Release Notes

公開日: 2026-09-18

Livery Organizer for FH6 v0.4.62 Previewでは、FH6上での整理作業とHTML上の整理状態をつなぎやすくするため、比較画面と「FH6で削除済み（仮）」の操作を拡張しました。あわせて、保存済み `C_livery` の構造を5項目で確認する作成方法監査スコアを追加し、同一内容の解析結果を再利用するキャッシュでレポート生成時間を抑えます。

任意の補助ツール **Navigator Bridge for FH6** は **v0.0.28** を継続します。車両メタデータも **2026-09-08更新 / 647車種 / package revision 2** を継続します。

## 比較画面から整理状態を直接変更

通常の比較画面で、表示中の各ペイントをその場で次の状態へ変更できるようになりました。

- 残す
- 削除候補
- 未決定

比較内容を確認した後に通常カードへ戻って状態を変更する必要がなくなり、似たペイントの確認と整理を同じ画面で進められます。

## 比較 / 再DL重複から「FH6で削除済み（仮）」へ反映

FH6上で削除したペイントは、通常カードだけでなく次の画面からも「FH6で削除済み（仮）」へ反映できます。

- 通常の比較画面
- 再ダウンロード完全一致の整理画面

反映後は、残っているペイントの実スロット番号と `#列U / D` のFH6位置を再計算します。現在の比較グループから対象が外れた場合も、残りの候補へ追随します。

「FH6で削除済み（仮）」はOrganizer内の一時的な整理状態です。FH6のGameSaveやファイルを削除する機能ではありません。FH6上での実際の削除は利用者自身が行います。

## 「FH6で削除済み（仮）」を検索して復元

復元画面へ検索欄と件数表示を追加しました。次の情報をまとめて検索できます。

- 車種名 / メーカー / モデル / 年式
- タイトル
- 作成者
- Car ID
- 元の実スロット番号
- FH6位置（`#001U` など）
- FH6表示日付
- 取得日時

複数語はAND条件として扱います。表示中の件数と全件数を確認しながら、対象を1件ずつ「元に戻す」で復元できます。

## 作成方法監査スコア

保存済み `C_livery` の構造から、次の5項目の統計的特徴を確認します。

1. 単一形状の占有率
2. 形状の多様性
3. 色の多様性
4. 最多色の占有率
5. 変形値の量子化傾向

利用者向けには、一致した条件数だけを **`0/5`～`5/5`** で表示します。カードの詳細、比較画面、CSV、Excelで確認でき、「監査スコア:高い順 / 低い順」でも並び替えられます。スコアを算出できないデータは、どちらの並び順でも末尾に配置します。

### スコアの意味

この監査は制作方法の事実認定ではありません。監査スコアは次の意味では使用しません。

- 自動生成である確率
- 判定の信頼度
- ペイントの品質
- 作者や作品の評価

また、スコアだけを使ってペイントを「手作業」「自動生成」などへ自動分類しません。解析できなかったこと自体も、自動生成の根拠にはしません。

## 同一内容を再利用する監査キャッシュ

作成方法監査の結果はGameSave外に保存し、`C_livery` の**内容SHA-256**をキーとして再利用します。

同一内容の `C_livery` が、再ダウンロード、別snapshot、複製などによって複数カードに現れる場合でも、同じ解析を繰り返しません。そのため、監査キャッシュ件数は表示カード数より少ない場合があります。これは同一内容で結果を共有しているためです。

キャッシュにはschema、校正ID、監査アルゴリズムversionも記録します。これらが現在の実装と一致しない古いキャッシュは使用せず、必要な内容を再計算します。

実データ確認では、初回のHTML生成 **63.15秒** に対し、監査キャッシュ利用時は **6.88秒** となり、約 **89.1%短縮（約9.2倍）** を確認しました。この値は確認時のデータ量・PC環境に依存する実測例であり、すべての環境で同じ時間になることを保証するものではありません。

## 内蔵ヘルプ

内蔵ヘルプを、現在の操作の流れと安全上の注意に沿って読み直せる構成へ整理しました。作成方法監査についても、5項目の意味、スコアが断定に使えないこと、同一データの解析結果をキャッシュで再利用することを説明しています。

日本語ヘルプの改訂に合わせ、英語リソースと翻訳監査も更新しています。

## Navigator Bridge / 車両メタデータ

Navigator Bridge for FH6は **v0.0.28** を継続します。FH6候補をタイトル完全一致 + `forzahorizon6.exe` の所有プロセスで確認し、通常移動キーの送信直前にも同じ対象を再検証する安全境界は変更していません。

同梱する車両メタデータも変更ありません。

- 収録車種: **647**
- metadata package revision: **2**
- source updated: **2026-09-08**
- Generator: **Vehicle DB Generator for FH6 v0.6.2**

起動時の自動通信や強制更新はありません。
